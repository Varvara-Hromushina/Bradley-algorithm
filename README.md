Проект реализует и сравнивает два подхода к бинаризации изображений документов:
  1) классический алгоритм Брэдли - адаптивный пороговый метод;
  2) модифицированный алгоритм Брэдли с предварительной коррекцией неравномерного освещения.

Алгоритм предназначен для обработки документов, сканов и изображений текста с неравномерным освещением, тенями или градиентами яркости.

Особенности:
  - два метода коррекции освещения: вычитание и деление;
  - автоматическая оценка фона с помощью гауссова фильтра;
  - комплексные метрики качества: Precision, Recall, F1-score;
  - детальная визуализация всех этапов обработки;
  - поддержка нескольких наборов данных: train/validation/test;
  - анализ матриц ошибок и временных характеристик;
  - автоматическое сопоставление изображений с ground truth.
